# LEOXIS 0.2 — Expansion Decision Intelligence
Status: Release candidate — staging only. Production promotion requires explicit approval.

## What's new
- Executive Decision Cockpit: decision gap, what must be true, biggest uncertainty and next action.
- Evidence & Assumption Risk: clearer visibility of submitted assumptions and evidence gaps.
- Comparable-store summary: decision context with demo/unverified evidence explicitly labelled where applicable.
- Commercial Negotiation: recommendation-first rental and store-size corridors. Sales and gross margin remain analytical assumptions, not negotiation levers.
- Outcome Learning: F90/F180/F365 approved-vs-actual review with operating variance analysis.

## Not part of the user release
Stage 6 enterprise data foundation, CSV validation and repository staging persistence remain platform infrastructure and are not presented as production customer-data capabilities.

## Release discipline
Staging first. Production remains unchanged until explicit approval. Expansion recovery and JavaScript preflight remain mandatory release gates.
